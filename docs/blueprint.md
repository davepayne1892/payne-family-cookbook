# **App Name**: Family Cookbook

## Core Features:

- Recipe Submission: Allow family members to submit new recipes via a beginner-friendly Markdown form.
- Recipe Display: Display recipes in a clear, consistent format from Markdown content.
- Tagging System: Implement a tagging system for recipes (e.g., ingredients, prep time).
- Recipe Search: Enable searching recipes by tags, ingredients, or keywords.
- Hands free recipe mode: a reader mode style view which emphasises a single step in a recipe, and allows easy navigation to the previous or next steps - to be used when actively cooking

## Style Guidelines:

- Primary color: Soft Olive (#A7C48D), evoking a sense of natural, home-cooked meals and family warmth.
- Background color: Very light beige (#F5F5DC) providing a neutral backdrop for recipes.
- Accent color: Muted Terracotta (#E07A5F) for highlights, conveying an earthy and inviting feel.
- Headline font: 'Playfair', a modern serif that brings a sophisticated yet approachable style.
- Body font: 'PT Sans', offering a friendly and legible appearance.
- Use simple, line-based icons for tags and search filters, indicating ingredients and timing.
- Clean, card-based layout for recipe previews, emphasizing visual appeal and ease of navigation.
